# Apartment Management System (DBMS Project)

## 📌 Overview
A complete apartment management system built using PHP, HTML, CSS, and MySQL. It manages tenants, rent, maintenance, custom roles, and administrative operations with a fully normalized database.

## 🚀 Features
- Tenant registration & management  
- Rent tracking  
- Maintenance log  
- Role-based access  
- Report generation  
- MySQL backend with normalized schema  

## 🧠 Database Components
- ER Diagram  
- Use Case Diagram  
- 3NF Normalized Tables  
- SQL queries for CRUD operations  

## 📂 Project Structure
- `/frontend/` → HTML/CSS UI  
- `/backend/` → PHP logic  
- `/db/` → SQL schema & queries  
- `/assets/` → Screenshots  

## ▶️ Tech Stack
- HTML, CSS  
- PHP  
- MySQL
